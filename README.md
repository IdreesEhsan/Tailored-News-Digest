# Tailored News Digest

Tailored News Digest is an AI-powered multilingual news intelligence and recommendation platform.

## Technology Stack

- Flutter
- FastAPI
- PostgreSQL / Supabase
- pgvector
- Python
- NLP / Transformer models

## Main Features

- Personalized news feed
- English and Urdu summaries
- Mood-aware recommendations
- Semantic recommendations
- Semantic search
- Gamification
- Premium content
- Accessibility
- Analytics
- Admin management
